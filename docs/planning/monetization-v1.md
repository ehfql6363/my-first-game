# 수익 모델 비교 v1 (수익 부서)

> 상태: 제안. 출시 전 법률·스토어 정책은 반드시 최신 공식 문서로 다시 확인할 것 (아래 수치와 규정은 2026-10 기준 일반적으로 알려진 내용이며 법률 자문이 아님).

## 전제
- 원칙(`docs/departments/monetization.md`): 메인 스토리는 과금 없이 끝까지. 스토리 단서는 가챠에 넣지 않는다.
- 게임 성격: 7일 스토리 + 회차 반복(로그라이트) + 수집(캡슐 기계). 짧고 진한 싱글플레이.
- 현재 기술: 웹 한 파일, 서버 없음. 캡슐 결과는 브라우저에서 결정 → 저장을 고치면 조작 가능.

## 후보 비교
| 모델 | 방식 | 장점 | 단점 / 위험 | 이 게임과의 궁합 |
|---|---|---|---|---|
| **A. 프리미엄(1회 구매)** | 스팀·모바일 유료 판매, 웹 1~2일차 무료 체험 | 서버 불필요. 확률형 아이템 규제와 무관. 스토리 게임 구매층과 맞음. 리뷰가 곧 마케팅 | 초기 노출이 어렵다. 판매 후 추가 수익이 없다 | ◎ 지금 구조 그대로 가능 |
| **B. 무료 + 코스튬 판매** | 게임 무료, 경비복·문루 귀 머리띠 등 외형만 판매 | 공정함(능력치 영향 없음). 가챠 규제 회피 | 외형을 보여 줄 화면이 적다(CCTV 게임) → 구매 동기가 약함 | ○ 도트 캐릭터가 더 보여야 효과 |
| **C. 무료 + 광고 보상** | 광고 시청 시 수당·캡슐 1회 | 진입 장벽 0. 웹·모바일에 쉬움 | 공포 몰입을 광고가 깬다. 수익 단가가 낮다 | △ 낮 숙직실에서만, 선택형이면 가능 |
| **D. 무료 + 유료 가챠** | 유료 재화로 캡슐 기계 | 수집형 게임의 최대 수익 모델 | 서버 추첨·결제 검증 필수. 확률 공개 의무와 분쟁 대응. "뽑기 = 갇힌 사람 구출" 스토리와 결합 시 윤리적 반감 위험. 1인 개발 운영 부담 큼 | △ 지금 단계에선 비추천 |
| **E. 시즌 패스 / 확장팩** | 새 밤(3~7일차 이후), 시즌 퍼레이드를 유료 확장으로 | 스토리 게임에 자연스러움. 출시 후 수익 | 콘텐츠를 계속 만들어야 함 | ○ A와 조합 좋음 |

## 추천: A + E (프리미엄 + 확장), 가챠는 게임 재화 전용 유지
1. **웹 무료 체험판**(1~2일차, 지금 아티팩트) → 반응 확인
2. **본편 1회 구매**(1~7일차 + 엔딩 3종). 가격대는 비슷한 인디 공포 게임과 비교해 출시 직전에 정한다
3. **확장**: 시즌 퍼레이드(할로윈·겨울) 밤 + 신규 동료·기념품을 유료 DLC 또는 무료 업데이트로
4. **캡슐 기계는 근무 수당(게임 안 재화)으로만**. 유료 재화를 붙이지 않는다

### 이유
- 지금 구조(서버 없음, 클라이언트 추첨)와 가장 잘 맞고, 보안 부서가 지적한 조작 문제가 수익과 무관해진다.
- "가챠 = 구출"이라는 스토리 반전은 **게임 재화일 때 감정적으로 성립**한다. 현금 뽑기와 결합하면 "사람을 돈 주고 뽑는다"로 읽힐 위험이 크다.
- 한국은 2024년 3월부터 확률형 아이템 정보 공개가 법적 의무다. 유료 가챠가 아니어도 우리는 확률을 이미 공개하고 있어 정책 변경 시 대응이 쉽다.

## 유료 가챠(D)를 나중에 넣는다면 필요한 것
- 서버 추첨과 결제 영수증 검증, 계정 시스템
- 확률·천장 공개(이미 데이터화 완료: `src/data/gacha.ts`), 확률 변경 이력 공지
- 미성년자 결제 보호, 환불 정책, 출시 국가별 규정 검토 (일부 국가는 유료 뽑기 자체를 강하게 규제)
- 스토어 수수료(애플·구글은 일반적으로 매출의 최대 30%, 소규모 개발자 프로그램은 더 낮음)를 반영한 가격 설계
