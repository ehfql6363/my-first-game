# 게임 방식 v2: 밤 CCTV 경비실 + 낮 덱빌딩

> 상태: 확정 방향(초안). 기존 뱀서식(A안)을 대체한다. 스토리·수칙서·동료·가챠 설정은 그대로 유지.

## 핵심 아이디어: 카드 한 벌로 밤과 낮을 잇는다
- **낮 (숙직실)**: 덱을 만든다. 캡슐 뽑기, 카드 보상 고르기, 강화, 제거, 수칙서 추리.
- **밤 (경비실)**: 만든 덱으로 CCTV를 보며 이상 현상에 대응한다.
- 밤과 낮이 같은 카드 시스템을 쓰므로, 개발할 시스템이 하나로 줄고 낮의 선택이 밤의 생존으로 바로 이어진다.

## 하루 흐름
```
[낮 · 숙직실]  수칙서 받기 → 수칙 추리(거짓 표시) → 캡슐 뽑기 → 카드 정비
      ↓
[밤 · 경비실]  00:00 ~ 06:00, CCTV 감시 + 카드로 대응
      ↓
[정산]        수당 지급, 카드 보상 3장 중 1장 선택, 스토리 진행
      ↓
다음 날 (총 7일 = 1회차)
```

## 밤: CCTV 경비실 (턴제)
- 시간은 **10분 단위 턴**으로 흐른다. 00:00 ~ 06:00 = 36턴.
- 매 턴: 카드 5장을 손에 들고, **배터리**(에너지) 3을 써서 카드를 낸다.
- 화면: 경비실 모니터. 카메라 6대 중 1대만 크게 보이고, 나머지는 작은 화면. 카메라 전환은 무료지만 한 턴에 볼 수 있는 큰 화면은 하나.
- 이상 현상이 카메라에 나타난다. 수칙서에 따라 올바른 카드로 대응해야 한다.
  - 예) 수칙 "웃는 마스코트가 보이면 그 구역 조명을 끄십시오." → 3번 카메라에 웃는 문루 → [조명 끄기] 카드를 3번 구역에 사용.
- 대응하지 않거나 틀리게 대응하면 **위험도**가 오른다. 위험도가 가득 차면 괴이가 경비실 문 앞에 도착한다 → 실패.
- 거짓 수칙대로 대응하면 위험도는 안 오르지만 숨은 보상과 단서를 놓친다. 거짓 수칙을 간파해 반대로 대응하면 큰 보상.
- 공포 연출: 카메라를 넘기는 사이에 문루가 한 칸씩 가까워진다. 정전 턴에는 모니터가 꺼지고 소리 단서만 남는다.

## 카드 종류
| 종류 | 예시 | 출처 |
|---|---|---|
| 기본 대응 | 조명 끄기, 문 잠그기, 방송 무시, 카메라 확대 | 시작 덱 |
| 근무 장비 | 손전등(정전 턴에 카메라 1대 유지), 호루라기(괴이 한 칸 후퇴), 무전기(동료 호출) | 캡슐, 보상 |
| 동료 카드 | 김반장 "대신 순찰"(한 구역 2턴 자동 대응), 이옥순 "소금"(구역 봉인), 하은 "야간 촬영"(정전 무시) | 캡슐 (동료 획득 시 전용 카드 추가) |
| 기념품 (유물) | 팝콘통: 수당 +10% / 저주: 매 밤 첫 턴 카드 1장 적게 | 캡슐 |
| 저주 카드 | "웃음소리" (손에 들어오면 쓸 수 없고 자리만 차지) | 수칙 위반, 문루 빚 |

- 도파민 장치: 같은 턴에 조건을 맞추면 연쇄 보너스 (예: 3구역 동시 봉인 → 수당 2배). 발라트로식 "터지는" 조합을 노린다.

## 낮: 숙직실 (덱빌딩)
- **수칙서 추리**: 오늘 밤 수칙서를 미리 읽고, 의심되는 수칙에 표시. 손글씨 메모, 지워진 줄 단서를 대조한다.
- **캡슐 기계**: 수당으로 뽑기. 장비·기념품·동료 → 덱과 유물에 추가.
- **카드 정비**: 카드 제거(덱 압축), 강화.
- **대화**: 동료, 민지와 짧은 대화로 스토리 진행.
- 연출: 숙직실 창밖은 늘 같은 오후. 시계는 빨리 돌고, 정문은 보이지 않는다. (낮에도 나갈 수 없다는 설정)

## 회차 구조 (B 반전과 연결)
- 1회차 = 7일. 밤에 실패하면 그 회차 종료 → **다음 회차는 1일차부터** (로그라이트).
- 회차가 끝나도 남는 것 (메타 진행): 구출한 동료, 일부 기념품, **이전 회차의 내 메모** (수칙서에 실제로 추가됨).
- 스토리상 "또 처음 출근하는 나"와 게임상 "다시 시작하는 런"이 같은 일이 된다.

## 한 달 개발 범위 (MVP 제안)
- 밤 2개 (1~2일차), 카메라 4대, 이상 현상 8종, 카드 20장, 동료 3명, 기념품 6개
- 낮: 캡슐 기계, 카드 보상, 수칙서 추리 화면
- 이후 확장: 3~7일차, 엔딩, 엔드게임

## 열린 질문
- 밤을 턴제로 할지, 실시간 + 일시정지로 할지 (현재 초안: 턴제. 모바일과 개발 난이도에 유리)
- 한 밤의 길이 (36턴이 길면 18턴 = 20분 단위)
