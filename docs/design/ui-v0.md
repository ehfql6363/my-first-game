## 글꼴 (목업용, Google Fonts)
- 공식 수칙(타자체), UI 본문: Nanum Gothic Coding
- 손글씨 메모: Nanum Pen Script
- 숫자, 영문 라벨 (도트 느낌): Silkscreen
- 실제 게임에서는 한글 도트 폰트(예: 갈무리체 등, 라이선스 확인 필요)로 교체 검토.

## 원칙
- 테두리는 둥근 모서리 대신 4px 계단식 그림자로 도트 느낌을 낸다.
- 캡슐 등급 = 색: 흰 / 파랑 #4f8dff / 보라 #a46bff / 금 #ffd76a / 검정(핑크 테두리).
- 확률표 버튼은 캡슐 화면에 항상 노출한다 (확률 공개 의무).

## 플레이 화면 HUD (목업 3번째 화면) — 폐기: 뱀서식 기준. 게임 방식 v2로 새로 만들 예정
- 상단: 체력 바(핑크) · 시계(해 뜨기까지 남은 시간) · 수칙서 버튼 / 레벨·경험치 바(민트) / 수당·처치 수
- 수칙 발동 시: 시계 아래 핑크 배너로 수칙 내용과 카운트다운 표시
- 공격 금지 적(웃는 문루): 민트 점선 고리 + "공격 금지" 라벨
- 정전: 손전등 주변 원형 시야만 남기고, 어둠 속 적은 눈(핑크 점)만 보임
- 응답 수칙: 화면 중앙 팝업, 안전한 선택지는 민트 버튼
- 하단: 근무 장비 6칸(테두리 색 = 등급) · 기념품(저주 있는 건 핑크) · 동료 초상화와 말풍선

## 밤 · 경비실 (목업, 게임 방식 v2)
- 상단: 배터리 3칸(노랑) · 위험도 바(핑크, 10칸) · 시계와 턴(36턴 중 n)
- 그날 밤 핵심 수칙 2개를 종이 띠로 고정 표시
- 큰 CCTV 화면 1개(초록빛 + 주사선, REC) + 아래 카메라 4대 썸네일(선택 = 민트 테두리). 썸네일에는 이상 현상을 표시하지 않음 (직접 봐야 앎)
- 손패 5장: 종이 카드, 좌상단 비용. 저주 카드는 보라 바탕 + 핑크 글씨, 비용 X
- 턴 종료 버튼(민트). 미대응 이상 현상 수만큼 위험도 상승

## 낮 · 숙직실 (목업, 게임 방식 v2)
- 밤과 대비되는 따뜻한 보라·주황 팔레트 (배경 #2a2140, 창밖 #f2a65a). 창밖은 늘 같은 오후, 정문 없음
- 수칙서 미리 읽기: 수칙마다 "의심" 표시 버튼 → 빨간 취소선
- 카드 보상 3장 중 1장 선택 (선택 = 위로 떠오름 + 민트 테두리)
- 하단: 수칙서 전체 / 캡슐 기계 / 덱 정비, 그리고 근무 시작 버튼
