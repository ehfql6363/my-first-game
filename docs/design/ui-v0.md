## 글꼴 (목업용, Google Fonts)
- 공식 수칙(타자체), UI 본문: Nanum Gothic Coding
- 손글씨 메모: Nanum Pen Script
- 숫자, 영문 라벨 (도트 느낌): Silkscreen
- 실제 게임에서는 한글 도트 폰트(예: 갈무리체 등, 라이선스 확인 필요)로 교체 검토.

## 원칙
- 테두리는 둥근 모서리 대신 4px 계단식 그림자로 도트 느낌을 낸다.
- 캡슐 등급 = 색: 흰 / 파랑 #4f8dff / 보라 #a46bff / 금 #ffd76a / 검정(핑크 테두리).
- 확률표 버튼은 캡슐 화면에 항상 노출한다 (확률 공개 의무).
