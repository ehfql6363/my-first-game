# 보안 부서

- 저장 데이터(localStorage 등)는 사용자가 조작할 수 있다고 가정한다. 불러올 때 형식과 범위를 검증하고, 깨진 데이터는 안전하게 초기화.
- 가챠 결과를 클라이언트만으로 결정하는 동안은 "조작 가능"함을 인지하고 문서에 남긴다. 유료 재화를 넣는 순간 서버 검증이 필요하다.
- 외부 스크립트, 외부 요청은 추가하지 않는다 (필요하면 이유를 문서화).
- 사용자 입력 텍스트(이름 등)는 HTML로 넣지 않는다.
- 의존성 추가 시 `npm audit` 확인.

## 현재 상태 (M2)
- 진행 저장: `localStorage`의 `happymoon-land/run`. 불러올 때 `src/core/save.ts`의 `parseRun`이 버전·정수 범위·알려진 카드/단서 id만 허용. 하나라도 어긋나면 무시하고 새 게임 (테스트 12종 + 브라우저 테스트)
- 수당은 클라이언트에만 있어 조작 가능. 유료 재화와 연결하기 전까지는 문제 아님
