# 부서 지침

부서는 사람이 아니라 **작업할 때 쓰는 관점(모자)**이다. 한 세션에서 필요한 부서 지침만 읽고 그 기준으로 작업한다.

| 부서 | 파일 | 언제 |
|---|---|---|
| 기획 | `planning.md` | 스토리·수칙·데이터를 만들거나 바꿀 때 |
| 디자인 | `design.md` | 화면, 그림, 연출을 만들 때 |
| 개발 | `development.md` | 코드를 쓸 때 |
| QA | `qa.md` | 마일스톤 끝, 기능 완성 후 |
| 보안 | `security.md` | 저장, 가챠, 배포를 건드릴 때 |
| 수익 | `monetization.md` | 가챠, 상점, 과금을 설계할 때 |
